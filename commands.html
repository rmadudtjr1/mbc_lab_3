명령어하는 일이럴 때
/grill-me에이전트가 거꾸로 나에게 질문해서 계획을 다듬음⭐ 뭘 원하는지 막연할 때
/goal목표가 완전히 끝날 때까지 알아서 계속 실행한 번에 끝까지 완성시키고 싶을 때
/learn잘된 작업 방식을 규칙으로 저장해 재사용반복 지시를 줄이고 싶을 때
/schedule반복 일정 또는 타이머로 실행 예약매일·매주 자동으로 돌릴 작업
/browser웹 브라우저를 직접 조작하는 서브에이전트 호출웹사이트 자료 수집 (정책상 차단될 수 있음)
/plan실행 전에 검토 가능한 구현 계획서를 먼저 작성실행 전에 계획을 확인·수정하고 싶을 때
/btw진행 중인 작업을 방해하지 않고 가벼운 질문을 별도 스레드로작업 중에 궁금한 게 생겼을 때
/boost여러 에이전트가 협력하는 심층 추론 모드복잡한 버그·어려운 문제를 풀 때
/teamwork-preview대규모 장기 작업을 에이전트 팀으로 수행저장소 전체 마이그레이션 같은 큰 작업
/antigravity-guideAntigravity 사용법 안내 (사내 스킬)막혔을 때 먼저 물어보기

/grill-me — 인터뷰 받기

비개발자가 가장 어려워하는 건 "무엇을 어떻게 지시해야 할지 모르겠다"입니다. /grill-me는 에이전트가 면접관처럼 질문을 던져 원하는 바를 끌어내 줍니다. 막연한 아이디어를 뒤에 그대로 적으면 됩니다.

/grill-me 부서에서 매주 쓰는 업무 보고서를 자동으로 만들고 싶은데 어떻게 해야 할지 모르겠어

질문에 구체적으로 답할수록 결과가 좋아집니다 — 자료 형태("엑셀 1개, 주간 실적이 행으로"), 결과물("A4 한 장, 표 1개 + 요약 3줄"), 독자("부서장 보고용")처럼요. 인터뷰가 끝나면 정리된 계획을 제시합니다.

/goal — 끝까지 실행

계획이 서면 /goal로 실행합니다. 중간에 멈추지 않고 목표 달성까지 스스로 진행합니다.

/goal 방금 정리한 계획대로 만들어줘. 샘플 데이터는 가상으로 만들어서 테스트까지 해줘.
사용 시 주의 자율성이 높은 만큼 진행 상황을 지켜보세요. 방향이 어긋나면 즉시 중단하고 다시 지시하면 됩니다. 파일을 지우거나 덮어쓰는 작업을 물어보면 내용을 반드시 읽고 승인하세요.

/learn — 방식 저장

결과가 만족스러웠다면 그 방식을 규칙으로 저장해 다음에 재사용합니다.

/learn 방금 보고서를 만든 방식을 규칙으로 저장해줘. 다음에 같은 요청을 하면 이 형식을 따르도록.

저장해두면 다음에는 "지난번 형식대로 이번 주 보고서 만들어줘" 한 마디면 됩니다. 반복 지시를 자산으로 바꾸는 것입니다.

/schedule — 예약 실행

같은 작업을 매일·매주 자동으로 돌립니다. 반복 주기와 할 일을 함께 적습니다.

/schedule 매주 금요일 오후 3시에 이번 주 보고서를 만들어서 바탕화면에 저장해줘
예약이 실행되려면 그 시각에 PC가 켜져 있고 Antigravity가 실행 중이어야 합니다. 설정에서 Prevent Sleep과 Keep In Menu Bar를 켜두면 안전합니다.

/browser — 브라우저 조작

웹 브라우저를 직접 조작하는 서브에이전트를 호출합니다. Google Chrome이 설치되어 있어야 합니다.

/browser 회사 홈페이지에서 최신 공지사항 3개 제목을 수집해줘
조직 정책으로 /browser가 차단된 환경에서는 동작하지 않습니다. 그 경우 다른 방법을 쓰세요.

/plan — 계획서 먼저 받기

/goal이 바로 실행이라면, /plan은 실행 전에 구현 계획서(아티팩트)를 먼저 만들어 보여줍니다. 계획서에 줄 단위로 의견을 달거나 수정을 요청한 뒤, 마음에 들 때 Proceed로 실행합니다.

/plan 주간 실적 엑셀을 읽어 부서장 보고용 요약 문서를 만드는 절차를 계획해줘

결과물이 중요하거나 되돌리기 어려운 작업일수록 /plan으로 시작하는 것이 안전합니다.

/btw — 작업 방해 없이 질문

에이전트가 긴 작업을 진행 중일 때, 그 작업을 끊지 않고 가벼운 질문을 별도의 백그라운드 스레드로 보냅니다.

/btw 아까 만든 파일은 어느 폴더에 저장했어?

본 작업은 계속 진행되고, 질문의 답만 따로 받아볼 수 있습니다.

/boost — 심층 추론

어려운 문제를 풀 때 여러 에이전트가 협력하는 심층 추론 모드를 켭니다. 오케스트레이터가 문제를 나눠 전문 에이전트들에게 맡기고, 가설을 검증해 답을 만듭니다.

/boost 이 매크로가 특정 조건에서만 잘못된 값을 내는 원인을 찾아줘
유료 플랜 전용 기능입니다 — 사내 라이선스(Gemini Enterprise Plus)에서는 사용할 수 있습니다. 일반 작업에는 과한 도구이니, 일반 지시로 풀리지 않는 복잡한 문제에만 쓰세요.

/teamwork-preview — 에이전트 팀

저장소 전체 마이그레이션이나 장기 리서치처럼 규모가 큰 작업을 에이전트 팀이 나눠 수행합니다. 시작하면 먼저 범위를 확정하는 인터뷰가 진행되고, 합의된 명세에 따라 팀이 움직입니다.

/teamwork-preview 이 폴더의 모든 보고서 양식을 새 템플릿으로 일괄 전환해줘
유료 플랜 전용이며 이름의 -preview처럼 아직 미리보기 단계 기능입니다. 교육 실습 범위를 넘는 큰 작업에만 고려하세요.

/antigravity-guide — 사용법 질문

Antigravity 사용법이 궁금하거나 막혔을 때 가장 먼저 쓰는 명령어입니다.

/antigravity-guide MCP 서버는 어떻게 추가해?

유틸리티 명령어

작업 지시가 아니라 화면·세션·설정을 다루는 보조 명령어들도 있습니다. 버전과 환경(데스크톱/CLI)에 따라 일부는 보이지 않을 수 있습니다.

명령어하는 일
/agents실행 중인 서브에이전트 패널을 엽니다. 각 서브에이전트의 상태(실행 중·완료 등)와 현재 단계를 보고, 승인 대기 중인 작업을 처리할 수 있습니다.
/resume이전 대화(세션) 목록을 열어 이어서 작업할 대화를 선택합니다.
/mcp연결된 MCP 서버 목록과 상태를 확인합니다.
/model대화에 사용할 모델을 전환합니다.
/effort모델의 추론 강도(effort)를 조절합니다. 높일수록 깊게 생각하는 대신 느려집니다.
/context현재 대화에 실려 있는 컨텍스트(파일·규칙 등) 현황을 확인합니다.
/hooks특정 시점에 자동 실행되는 훅(hook) 설정을 관리합니다.
/codesearch코드베이스를 검색합니다. /cs, /search로 줄여 쓸 수 있습니다.
스킬도 슬래시 명령어가 됩니다 설정의 Customizations에 설치된 스킬은 자동으로 /스킬이름 명령어로 등록됩니다. /antigravity-guide가 바로 그 예이며, 직접 만든 스킬도 같은 방식으로 호출할 수 있습니다. 그래서 실제 / 목록에는 여기 적힌 것보다 많은 항목이 보일 수 있습니다.
